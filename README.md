# Fitline

Fitline is a modern fashion e-commerce website built with React and Vite.  
It includes product browsing, category pages, and a shopping cart experience.

## Features

- Home page
- Women, Men, and Accessories pages
- Product cards
- Shopping cart
- Responsive layout

## Tech Stack

- React
- Vite
- React Router DOM
- Tailwind CSS

## Installation

```bash
npm install
```
